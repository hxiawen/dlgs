About

Dualogues is a Chrome extension designed for heavy AI chat users. When ChatGPT conversations get long, finding a specific message often requires endless scrolling. Dualogues provides visual navigation on the right side of the page, letting you jump to any position with a single click.

Widget Track Lines

Compact track line markers on the right side of the page visually reflect the conversation structure and density.

Panel Sidebar

Hover over a track line to expand the panel and browse the full list of questions without leaving the current page.

Precise Navigation

Click any question block and the page smoothly scrolls to the corresponding position, quickly locating the conversation content.

Auto Theme Adaptation

Automatically follows ChatGPT's light/dark theme switching, keeping the visual style consistent at all times.

FAQ

Nothing happens after installation?
Make sure you are currently on a chatgpt.com page and have logged into ChatGPT. Dualogues only runs on the ChatGPT website and will not activate on other sites.
Can't see the Widget track lines?
The page needs at least one message you sent (a user message) for the Widget to display track line markers. If the conversation just opened and hasn't finished loading, please wait a few seconds.
Scroll position is inaccurate?
ChatGPT's page structure may change with version updates, which could cause scroll position offsets. If you encounter this issue, please report it to us through the contact information below, and we will adapt as soon as possible.
How do I delete extension stored data?
All Dualogues data is stored locally in your browser (IndexedDB) and is never uploaded to any server. You can manage data through:
  • Type chrome://settings/content/all in the Chrome address bar, find chatgpt.com, and click "Clear data".
  • Or simply uninstall the Dualogues extension, and all extension-related data will be automatically removed.
Does Dualogues read my conversation content?
Dualogues needs to read message text on the page to extract question summaries for display in the Panel. All processing is done locally in your browser, and no data is sent to external servers. See the Privacy Policy below for details.

Data & Privacy

Dualogues respects your privacy. All data required for the extension to operate is stored locally in your browser (IndexedDB and chrome.storage), and is never uploaded, transmitted, or shared with any third party.

Specifically:

  • Does not collect personal identity information, account information, or conversation content.
  • Does not send any data to external servers. No analytics tracking, no remote logging.
  • Does not connect to any third-party services. The extension runs entirely offline.
  • Data is used solely for maintaining navigation functionality locally (such as remembering conversation structure), and uninstalling the extension clears all data.

For the full privacy policy, see below.

Privacy Policy

Last updated: 2026-05-02

1. Overview

Dualogues ("the Extension") is a Chrome browser extension that helps users navigate long ChatGPT conversations. This privacy policy explains how the Extension handles user data.

2. Data Collection

The Extension does not collect any personal identity information. Specifically:

  • It does not collect names, email addresses, phone numbers, or other personal identity information.
  • It does not collect ChatGPT account information or login credentials.
  • It does not use cookies or any tracking technologies.
  • It does not collect browsing history or information about other websites visited.

3. Data Usage

The Extension processes page content locally in the browser to enable the following features:

  • Detecting user messages in ChatGPT conversations and generating question summaries.
  • Displaying conversation structure markers in the Widget on the right side.
  • Presenting a clickable list of questions in the Panel.
  • Navigating to the corresponding position in the conversation based on user clicks.

All processing is done locally in the user's browser, and the processed data is used solely for local display and navigation functionality.

4. Data Storage

The Extension uses the following browser-local storage mechanisms:

  • IndexedDB: Stores conversation structure and question summaries for restoring navigation state across page refreshes. Data is isolated by ChatGPT conversation ID.
  • chrome.storage.local: Stores user preference settings (such as whether the panel is pinned). It does not contain any conversation content.

All data is stored locally on the user's device and is never uploaded to any server. Data retention lasts as long as the extension is installed; uninstalling the extension automatically deletes all data.

5. Data Deletion

Users can manage or delete data through the following methods:

  • Type chrome://settings/content/all in the Chrome address bar, find chatgpt.com, and click "Clear data".
  • Uninstall the Dualogues extension, and all extension-related data will be cleared.

6. Third-Party Services

The Extension does not connect to any third-party services, including but not limited to:

  • It does not use third-party analytics or tracking services (such as Google Analytics).
  • It does not use third-party advertising services.
  • It does not share any data with any third party.
  • It does not call any remote APIs.

7. Permissions

The Chrome permissions requested by the Extension and their purposes:

  • Access chatgpt.com page content: Read conversation message structure to generate navigation markers.
  • Local storage: Save conversation navigation data and user settings locally in the browser.

The Extension does not request any sensitive permissions (such as bookmarks, history, downloads, tab management, etc.).

8. Children's Privacy

The Extension is not directed at children under 13 and does not knowingly collect personal information from children.

9. Policy Changes

This privacy policy may be revised as extension features are updated. Significant changes will be communicated to users in the extension update notes. Continued use of the extension constitutes acceptance of the revised policy.
