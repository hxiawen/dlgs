产品介绍

Dualogues 是一款 Chrome 扩展，专为频繁使用 AI 对话的用户设计。当 ChatGPT 对话变得很长时，找到某条特定消息往往需要反复滚动。Dualogues 在页面右侧提供可视化导航，让你一键跳转到任意位置。

Widget 轨道线

页面右侧显示紧凑的轨道线标记，直观反映对话结构和密度。

Panel 侧边面板

悬停轨道线即可展开面板，浏览完整的问题列表，无需离开当前页面。

精准导航跳转

点击任意问题块，页面自动平滑滚动到对应位置，快速定位对话内容。

主题自动适配

自动跟随 ChatGPT 的浅色/深色主题切换，视觉风格始终一致。

常见问题

安装后没反应？
请确认你当前处于 chatgpt.com 页面，并且已经登录 ChatGPT。Dualogues 仅在 ChatGPT 网页上运行，不会在其他网站激活。
看不到 Widget 轨道线？
页面上需要至少存在一条你发送的消息（用户消息），Widget 才会显示轨道线标记。如果对话刚打开尚未加载完成，请稍等几秒。
跳转位置不准？
ChatGPT 的页面结构可能随版本更新而变化，这可能导致跳转位置出现偏差。如果遇到此问题，请通过下方联系方式反馈给我们，我们会尽快适配。
如何删除扩展存储的数据？
Dualogues 的所有数据存储在浏览器本地（IndexedDB），不上传到任何服务器。你可以通过以下方式管理数据：
  • 在 Chrome 地址栏输入 chrome://settings/content/all，找到 chatgpt.com，点击"清除数据"。
  • 或直接卸载 Dualogues 扩展，扩展相关数据将自动清除。
Dualogues 会读取我的对话内容吗？
Dualogues 需要读取页面上的消息文本以提取问题摘要，用于在 Panel 中显示。所有处理都在你的浏览器本地完成，不会将任何数据发送到外部服务器。详见下方隐私政策。

数据与隐私

Dualogues 尊重你的隐私。扩展运行所需的所有数据均存储在浏览器本地（IndexedDB 和 chrome.storage），不会上传、传输或分享给任何第三方。

具体来说：

  • 不收集个人身份信息、账户信息或对话内容。
  • 不发送任何数据到外部服务器。无分析追踪、无远程日志。
  • 不连接任何第三方服务。扩展完全离线运行。
  • 数据仅用于在本地维持导航功能（如记住对话结构），卸载扩展即全部清除。

完整的隐私政策请见下方。

隐私政策 / Privacy Policy

最后更新 / Last updated: 2026-05-02

1. 概述 / Overview

Dualogues（"本扩展"）是一款 Chrome 浏览器扩展，帮助用户在 ChatGPT 长对话中导航。本隐私政策说明本扩展如何处理用户数据。

2. 数据收集 / Data Collection

本扩展不收集任何个人身份信息。具体而言：

  • 不收集姓名、邮箱、电话等个人身份信息。
  • 不收集 ChatGPT 账户信息或登录凭据。
  • 不使用 Cookie 或任何追踪技术。
  • 不收集浏览历史或访问的其他网站信息。

3. 数据使用 / Data Usage

本扩展在浏览器本地处理页面内容，以实现以下功能：

  • 检测 ChatGPT 对话中的用户消息，生成问题摘要。
  • 在右侧 Widget 中显示对话结构标记。
  • 在 Panel 面板中展示可点击的问题列表。
  • 根据用户点击导航到对话中的对应位置。

所有处理均在用户浏览器本地完成，处理后的数据仅用于本地展示和导航功能。

4. 数据存储 / Data Storage

本扩展使用以下浏览器本地存储机制：

  • IndexedDB：存储对话结构和问题摘要，用于跨页面刷新后恢复导航状态。数据按 ChatGPT 对话 ID 隔离存储。
  • chrome.storage.local：存储用户偏好设置（如面板是否固定）。不包含任何对话内容。

所有数据存储在用户设备本地，不上传至任何服务器。数据保留期限与扩展安装期限一致，卸载扩展后数据自动删除。

5. 数据删除 / Data Deletion

用户可以通过以下方式管理或删除数据：

  • 在 Chrome 地址栏输入 chrome://settings/content/all，找到 chatgpt.com，点击"清除数据"。
  • 卸载 Dualogues 扩展，所有扩展相关数据将被清除。

6. 第三方服务 / Third-Party Services

本扩展不连接任何第三方服务，包括但不限于：

  • 不使用第三方分析或追踪服务（如 Google Analytics）。
  • 不使用第三方广告服务。
  • 不与任何第三方共享数据。
  • 不调用任何远程 API。

7. 权限说明 / Permissions

本扩展请求的 Chrome 权限及其用途：

  • 访问 chatgpt.com 页面内容：读取对话消息结构以生成导航标记。
  • 本地存储：在浏览器本地保存对话导航数据和用户设置。

本扩展不请求任何敏感权限（如书签、历史记录、下载、标签页管理等）。

8. 儿童隐私 / Children's Privacy

本扩展不面向 13 岁以下儿童，不有意收集儿童的个人信息。

9. 政策变更 / Policy Changes

本隐私政策可能随扩展功能更新而修订。重大变更将在扩展更新说明中告知用户。继续使用扩展即视为同意修订后的政策。
